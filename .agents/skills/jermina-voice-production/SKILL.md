# Jermina Voice Production & Empirical Acting Engine

Ця навичка містить повний стек знань, інструкцій та коду для синтезу живого, експресивного людського та синтетичного мовлення через **Gemini 3.8 Live API**.

---

## 1. Коли активувати цю навичку
- Озвучення сценаріїв, Shorts/TikTok роликів, подкастів, кінореплік або блогерських відео.
- Необхідність передати складні емоції: нестримний живий сміх, фізичний плач і відчай, чуттєву спокусу з vocal fry, ніжність, лють або зловісне шепотіння.
- Генерація промптів для персонажів за емпіричною граматикою мовлення.
- Інтеграція з REST API сервісом `jermina-voice` на порті `8088`.

## 3. Dynamic Prompt Builder Grammar

Будь-який запит на синтез має формувати системну інструкцію за такою трирівневою структурою:

```python
def build_universal_instruction(role: str, baseline_state: str, context_description: str) -> str:
    return f"""
ТИ — {role.upper()}.
БАЗОВИЙ НАСТРІЙ: {baseline_state.upper()}.
КОНТЕКСТ СЦЕНИ: {context_description}

СУВОРІ ПРАВИЛА АКТОРСЬКОЇ ГРИ ТА ОЗВУЧКИ:
1. ТЕГИ В ДУЖКАХ ТА ЗІРОЧКАХ — ЦЕ ВКАЗІВКИ ДЛЯ ГОРЛА, ДИХАННЯ ТА ЗВ'ЯЗОК:
   Ніколи не читай слова в дужках або зірочках як текст! Відтворюй їх тілом, звуком та інтонацією.
2. ФІЗИЧНЕ ПЕРЕВТІЛЕННЯ:
   - Втілюй зазначений фізіологічний стан (переривчасте дихання, vocal fry, наспівність, крик, шепіт).
   - ЖОДНОГО штучного 'ха-ха'! Тільки живі розмовні реакції, регіт крізь слова.
   - Дефіси та три крапки — це судомні вдихи, затинання або живі паузи.
3. ЖОДНОГО ДИКТОРСЬКОГО ПАФОСУ:
   Ти не читаєш чужий текст, ти живеш цією реплікою в цю саму секунду.
"""
```

## 4. Виклик через REST API (`jermina-voice`)

Сервіс доступний за адресою `http://127.0.0.1:8088`.

### Отримати каталог голосів:
```bash
curl -s http://127.0.0.1:8088/api/v1/voices | jq .
```

### Згенерувати мовлення:
```bash
curl -X POST http://127.0.0.1:8088/api/v1/synthesize \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Пфф!.. Та ні, ви серйозно?! Ой, не можу... та це ж просто геніально!",
    "voice": "Zephyr",
    "role": "blogger",
    "state": "нестримний сміх",
    "context": "Блогерка регоче з коментаря підписника",
    "output_filename": "output/audio/viral_laugh.wav"
  }'
```

### Згенерувати ідеальний системний промпт:
```bash
curl -X POST http://127.0.0.1:8088/api/v1/prompt-builder \
  -H "Content-Type: application/json" \
  -d '{
    "role": "кібер-психопатка",
    "state": "зловісне шепотіння",
    "context": "Шепоче глядачеві про стеження через вебкамеру"
  }'
```
