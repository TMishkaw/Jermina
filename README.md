# Jemini Core Library

> **Jemini** — це незалежна, модульна Python-бібліотека з відкритим кодом для повного циклу автономного створення контенту, публікації, аналізу ефективності та саморозвитку контент-каналів на базі Gemini API.

---

## 🏛 Архітектура середовищ (Git Flow)

Система розділена на два рівні ізоляції:

1. **Рівень бібліотеки (`jemini-core`)**:
   - `dev`: єдине робоче середовище для розробки нового функціоналу, плагінів та виправлення багів.
   - `Antigravity` (тестовий контур): псевдореальне середовище для верифікації. Тестувальники фіксують проблеми через GitHub Issues.
   - `main` / `release`: продакшен-ревізія бібліотеки, куди код потрапляє виключно після успішного проходження тестів.

2. **Рівень контент-проєктів (Каналів)**:
   - Кожен канал функціонує в окремому ізольованому робочому середовищі, підключаючи `jemini` як залежність.
   - Агент каналу має повну автономію в межах конфігурацій, сценаріїв та експериментів свого проєкту без змін у ядрі.

---

## 🧩 Основні модулі системи

1. **Модуль 1: Мозок та ієрархічний контекст (`jemini.core`)**
   - *Core Base Layer*: незмінні системні правила та принципи роботи.
   - *Domain Knowledge*: вертикальні знання (сценаристика, монтаж, кодогенерація).
   - *Instance / Channel Specific*: персональний профіль каналу (стиль, тональність, ліміти, цілі).

2. **Модуль 2: Ротатор ключів та керування квотами (`jemini.rotator`)**
   - Централізований пул Gemini API-ключів.
   - Автоматичний облік лімітів та перехоплення помилок 429 (Too Many Requests).
   - **Hot Standby**: миттєве безшовне перемикання активних сесій та стрімів без втрати з'єднання.

3. **Модуль 3: Мультимодальний аналізатор та синтез (`jemini.multimodal`)**
   - *Live API Stream*: двосторонній потік відео/аудіо в реальному часі (Gemini 3.8 Live API).
   - *Voice Production*: акторське втілення мовлення (Zephyr, Aoede, Fenrir, Kore) згідно з еталонним стандартом (vocal fry, природний сміх, шепіт).

4. **Модуль 4: Публікатор (`jemini.publisher`)**
   - Дистрибуція готового контенту у **YouTube** (звичайні відео та YouTube Shorts) та **TikTok** (вертикальні відео).

5. **Модуль 5: Оцінка ефективності та саморозвиток (`jemini.analytics`)**
   - Автоматичний збір метрик та аналітика залученості.
   - Система контрольованих експериментів (Core Theme + керовані девіації).
   - Агентне самодопрацювання (генерація звітів, ідей та Pull Request'ів).

6. **Інфраструктура та пам'ять (`jemini.storage` & `jemini.api`)**
   - СУБД: **PostgreSQL** + **pgvector** для довготривалої асоціативної пам'яті агентів.
   - REST API (FastAPI) з автоматичною документацією Swagger/OpenAPI.
   - Автономна вбудована Wiki-база знань.

```bash
python -m uvicorn jemini.api.app:app --reload --port 8000
```
