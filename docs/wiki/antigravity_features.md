# Можливості та функції Antigravity App (Knowledge Base)

> **Antigravity App** — це нативне робоче середовище для AI-агентів розробки з розширеними можливостями контролю, безпеки, автоматизації та мультимодальної взаємодії.

---

## 1. Проєкти та ізоляція середовищ (Projects)

- **Підтримка Git Worktrees**: проєкти нативно підтримують роботу з git-ворктрі, що дозволяє агентам виконувати задачі в ізольованих фонових каталогах без конфліктів з активною гілкою розробника.
- **Scoped Settings (Ізольовані налаштування)**: гнучке налаштування безпеки окремо для кожного проєкту (`Default`, `Full machine`, `Unrestricted`).
- **Scoped Permissions (Збереження дозволів)**: дозволи на виконання дій, надані агенту під час діалогу, зберігаються між сесіями.
- **Multi-folder Access**: можливість для агента працювати одночасно з кількома директоріями та кодовими базами в межах одного проєкту.

---

## 2. Автоматизація та планування (Scheduled Tasks)

- **Періодичні задачі**: планування відправки повідомлень та інструкцій агентам за часовими тригерами за відсутності користувача.
- **Рушій Gemini 3.8 Flash**: швидка та точна генерація й перевірка стану.
- **Хвилинна точність**: виконання за точним хвилинним розкладом.

---

## 3. Голосова взаємодія (Live Voice Transcription)

- **Швидкий виклик**: клавіші `Ctrl + M` для запуску або зупинки голосового введення.
- **Live View**: транскрипція мовлення в реальному часі безпосередньо у поле введення промту.
- **Smart Cleanup**: автоматичне очищення транскрипції від пауз, слів-паразитів, повторень та самовиправлень.
- **Контекстна обізнаність**: модель враховує термінологію проєкту під час розпізнавання.
- **Застосування**: як для основних промтів, так і для коментарів до артефактів (кодових дифів, планів).

---

## 4. Перехоплювачі життєвого циклу (JSON Hooks)

- Можливість виконання локальних shell-скриптів на ключових стадіях роботи агента:
  - *Перед викликом інструменту (pre-tool)*
  - *Після відповіді моделі (post-response)*
  - *При зупинці циклу (loop stopping condition)*
- Конфігуруються глобально або локально для кожного воркспейсу через прості JSON-файли.

---

## 5. Браузерний субагент (Browser Subagent)

- **Виклик на вимогу**: через слеш-команду `/browser`.
- **Chrome DevTools MCP**: нативна інтеграція для глибокого аналізу DOM, мережі та консолі.
- **Запис відео**: фіксація браузерних сесій у форматі WebM.

---

## 6. Віддалений моніторинг (Remote Control)

- **Мобільність**: запуск тривалих агентних задач на робочій станції та контроль виконання з будь-якого мобільного пристрою чи браузера.
- **Збереження локального контексту**: повний доступ до локальної файлової системи, інструментів та креденшалів робочої станції.
- **Push-сповіщення**: отримання повідомлень у браузері про завершення задачі або необхідність підтвердження.

---

## 7. Вбудована система контролю версій (VCS Panel)

- **Review панель**: перегляд staged / unstaged змін, дифи гілок та окремих правок інструментів агента.
- **Управління**: стейджинг файлів, створення комітів з автоматичною генерацією commit messages та відправка (`push`) у репозиторій.
