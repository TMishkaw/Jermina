# Git Flow & Життєвий цикл коду Jemini

## 1. Рівні ізоляції
1. **Бібліотека (Core)**:
   - Розробка ведеться суворо в гілці `dev`.
   - Жоден код не потрапляє в `main` без тестування в тестовому контурі `Antigravity`.
   - Тестувальники та тестові агенти **не редагують код напряму**, а створюють GitHub Issues.
2. **Канали**:
   - Підключають `jemini` через версіоновані релізи/пакети.
   - Експерименти каналу не впливають на стабільність ядра.
